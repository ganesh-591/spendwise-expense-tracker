# SpendWise – Personal Expense & Budget Tracker

SpendWise is a responsive personal finance web application that helps users manage income, track expenses, monitor monthly budgets, and understand their spending habits through financial insights and visual reports.

## Features

- **Dashboard:** View total balance, income, and expenses.
- **Transaction Management:** Add, edit, delete, search, and filter transactions.
- **Category Breakdown:** Analyze expenses by category.
- **Financial Insights:** View total transactions, average expenses, and highest spending.
- **Monthly Budget:** Set a budget and monitor spending progress with alerts.
- **Monthly Financial Report:** View income, expenses, savings, and savings rate.
- **Monthly Expense Chart:** Visualize category-wise expenses.
- **Monthly Savings Trend:** Track income, expenses, and savings over recent months.
- **Local Storage:** Keep transaction data saved in the browser.

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start managing your transactions.

No backend or database setup is required.

## Data Storage

SpendWise uses browser LocalStorage to save transaction data. Data remains available in the same browser unless its site data is cleared.
